.venv-build\Scripts\activate

Build command 
pyinstaller outpost-backend.spec

Test the exe directly
.\dist\outpost-backend.exe

If that works, copy it to Tauri binaries
Copy-Item dist\outpost-backend.exe frontend\src-tauri\binaries\outpost-backend-x86_64-pc-windows-msvc.exe -Force

Then test the full system
cd frontend
npm run tauri dev

If the sidecar exe is locked. Kill it first:
taskkill /IM outpost-backend.exe /F
